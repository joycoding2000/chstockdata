1. **有限元数据/机器能发现什么？** 发行人＋期间分组、不同公告 ID/日期/已取得 SHA，可发现重复全文；补充/更新标题及比较列/政策关键词可发现候选；直接前后列可给出金额差异候选。本文已在固定集合实测这些能力。
2. **哪些必须读正文？** 通知到底改什么、修改的是哪主体哪期间、是否只有 EPS、比较列实际金额及顺序。中南一页、万科两页必须完整读取相关范围；不是要求每次从头人工阅读 270 页，而是不能只凭标题给金额结论。
3. **读完仍需什么独立核验？** 单位/列归属和标签映射、与独立原报对齐、完整链及最早可知日、跨主体提及与真正受影响主体。当前由 Agent 作了有限语义判断，真人独立复核没有执行；其质量不能自动认证成供应 SLA。
4. **明确漏检机制有哪些？** 常规年报中的比较期调整不必有更正标题；仅按目标年度原报告分组会漏掉下一年度的比较列；宽关键词又会把治理通知和 EPS-only 混入金额候选。跨页单位串用是已观察的错误值机制。目录未覆盖的标题、同 URL 静默变更属于未认证风险，没有在本轮观测成既定事实。
5. **没有发现异常，能直接用今天的结构化旧期值吗？** **不能。** 候选发现的否定结果不证明无修订，更不能提供原值、原版与首次可知日期。
6. **fail-closed 会令多大范围不可用？** 不能估计全市场比例。逻辑上，所有**尚未正向绑定原件/期间/单位/版本与可用日**的历史输入都不能凭无报警放行，涉及普通行而不只是已知更正清单。固定试验的首次 4 个未知字段、V2 的 3 个错误，以及严格 T 的 15/33 UNKNOWN 分别保留，不能拼成市场失败率。
7. **有没有正向认证方式？** 有：把实际原件中的每个必要事实及比较期、单位、版本身份、可用日正向绑定；跨源数值仅在该锚下验证；影响范围未知则停。它可以避免依赖“没找到更正”，但普通报告也需进入认证。**该全量事实认证流程的无监督准确性、完整发现范围、自动语义校验及人工异常上限，本轮均未证明。** 不能把有界账本演示说成已经交付了这种能力。

所以，现有材料支持“检索和数字读取有用”，尚不支持“免费结构化普通行基本安全，人工只看少数异常”的经济前提。未知修订召回率保持 `NOT_ESTABLISHED`，不因固定样本检测到了已知变化而升级。
