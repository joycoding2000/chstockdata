## Source semantics 与根因

实现链：a_stock._suspension_snapshot_page → suspension._load_suspension_snapshot → fetch_suspension_info；legacy get_suspension_info 委托 structured acquisition；fetch_tradability 依赖日历、官方退市生效日、停牌结果。

Endpoint：https://datacenter-web.eastmoney.com/api/data/v1/get，reportName=RPT_CUSTOM_SUSPEND_DATA_INTERFACE。日期外查询参数保持一致：MARKET=全部、columns=ALL、pageSize=500、sortColumns=SUSPEND_START_DATE、sortTypes=-1、source/client=WEB。通过现有 a_stock._em_get 节流顺序获取全部声明分页，没有全市场并发扫描。

| DATETIME 查询日期 | 行数 / count | 页数 | 查询日以后的 start 行数 |
| --- | ---: | ---: | ---: |
| 2015-01-05 | 4087 / 4087 | 9 | 4082 |
| 2016-01-04（已知万科停牌案例） | 3723 / 3723 | 8 | 3702 |
| 2020-02-03 | 2071 / 2071 | 5 | 2067 |
| 2022-12-30 | 1141 / 1141 | 3 | 1137 |
| 2026-09-11 | 43 / 43 | 1 | 29 |
| 2026-10-09（当前对照） | 17 / 17 | 1 | 0 |

查询结果发生实质变化；不能声称 DATETIME 完全被忽略。它也不等于指定日期的完整历史状态。2015-01-05 的 4087 行仅有 4087 个证券代码，不是完整逐事件历史。原始字段包括 SUSPEND_START_TIME、SUSPEND_END_TIME、SUSPEND_START_DATE、PREDICT_RESUME_DATE；没有独立 historical-as-of 完整性声明或历史披露时间。

独立反证：[万科公司披露的重组预案修订稿](https://static.cninfo.com.cn/finalpage/2016-07-02/1202445845.PDF)，第 112 页记载 2015-12-18 开始停牌并于 12-21 进入重组停牌程序。2016-01-04 endpoint 查询却只返回万科 2017-07-17 的较晚事件，遗漏该次历史停牌；因此简单过滤 latest row 的 start/end 无法重建完整历史状态。独立来源信息见 [independent-source-evidence.json](evidence/2026-10-09-v0.4.2-release/independent-source-evidence.json)。

当前名单也包含复牌日记录：603183 在 2026-10-09 响应中，SUSPEND_END_TIME 为 2026-10-08 15:00，预计复牌日期为 2026-10-09。把命中一律当作 suspended=True 会误判当日状态。

裁决：观测到的是按 DATETIME 条件筛选的最近停复牌事件列表，可含历史事件和查询日后的事件；**完整 historical as-of 能力不成立**。当前日名单可在完整获取及事件日期校验后用于有限当前日判断。服务端精确 DATETIME 谓词没有公开权威定义，保留为 UNRESOLVED_RISK，不猜测内部 SQL。预计复牌日期不能证明完整历史覆盖或历史可知信息集。

根因（CONFIRMED_DEFECT）：旧代码将该列表误称历史快照；命中就 True，未命中就 False；data_as_of 被写成历史查询日。派生 tradability 又把任意 normal_empty 直接转成 True，包括没有明确 suspended=False 的 payload。

Raw evidence 在 [集中 evidence 目录](evidence/2026-10-09-v0.4.2-release/)：27 份 raw-日期-page-N.json 保存完整合法响应，[source-probe.json](evidence/2026-10-09-v0.4.2-release/source-probe.json) 和 [source-probe-2016-01-04.json](evidence/2026-10-09-v0.4.2-release/source-probe-2016-01-04.json) 保存每次请求参数、UTC 查询时间、HTTP 状态、摘要及 SHA256。[probe_suspension.py](evidence/2026-10-09-v0.4.2-release/probe_suspension.py) 保留实际探针逻辑。
