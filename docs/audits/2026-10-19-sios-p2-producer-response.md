## 3. 最小交付方式、成本与是否改 chstockdata

下表为基于现有结构的**工作量判断，非已完成工时或供应商报价**，不含账号开通等待。没有本轮核实的人民币采购价格；不把积分数换算为固定费用。

| 路径 | 预计新增工作 | 现实条件与取舍 | 修改生产代码 |
| --- | --- | --- | --- |
| Owner/供应商已有合格离线包 | 约 0.5—1 人日验收、归档 | 最低成本；本轮检查范围未发现此包，必须先收到实际文件。若满足合同，立即停止增加工程 | 不需要 |
| 成熟供应商直接导出：RQData 优先；已有合格 Tushare 权限可优先复用 | 约 1—2 人日导出及验收；必要规则缺口可使其停止 | 最接近合同；先要可用权限/导出文件，三个指定日全月份及元数据必须实验收；目前没有供应商认证调用证据 | 不需要；消费者可直接读取 CSV/Parquet |
| 免费 SHFE + 新浪 + DCE 拼接 | 至少约 3—5 人日的定向导出/核对，完整补洞上限未知，不建议投入 | DCE 月份全集、125 行已见结算缺口、历史元数据/单位均需解决；当前不能给出有界交付保证 | 可以做离线，但不能据此保证低成本 |
| 新增 chstockdata 最小期货能力 | 单独 CR 评估；生产接入/发布另计，本轮不授权 | 不能创造上游数据或权限；本次仅一个消费者，增加 SDK 并不能减少当前阻断 | 当前无必要，不实施 |

供应商路径仅核验决定接口的当前官方文档，未重做来源综述：

- [RQData 期货接口](https://www.ricequant.com/doc/rqdata/python/futures-mod)提供交易所日线 `futures.get_exchange_daily` 和按日期查询乘数 `futures.get_contract_multiplier`；应优先交易所日线原值，不能只拿连续主力或 tick 合成日线代替。
- [RQData 通用合约接口](https://www.ricequant.com/doc/rqdata/python/generic-api)支持历史日期清单、合约详情等。应使用 Future 类型再筛 underlying_symbol=CS；type=CS 在其接口中代表股票。当前 tick_size/最新交易时段不自动具备历史有效日期。
- [Tushare fut_basic](https://tushare.pro/document/2?doc_id=135)与 [fut_daily](https://tushare.pro/document/2?doc_id=138)是备选，当前文档均写至少 2000 积分；日线单次上限 2000 条、合约表上限 10000 条，须核分页/分段及返回截断。商品交易单位看 per_unit/trade_unit，不能误用仅适用金融期货的 multiplier 列。权限及五品种历史字段本轮未实取。

**建议最小离线包**（尚未生成，不是本次样本目录）：

```text
exports/sios-p2/2020-2025/<source-export-id>/
  daily.csv                 # 或 Parquet，原始月份日线、原结算与成交价
  contracts.csv             # 含退市合约、上市/最后交易/交割年月
  contract_terms.csv        # 乘数/tick/规则及有效日期，未知字段显式 UNKNOWN
  calendar.csv              # 两交易所交易日期、来源、特殊日/夜盘解释
  coverage.csv              # 按年份×品种×字段的分母/实得/缺失率
  gaps.csv                  # 具体交易日×合约×字段及原因
  quality_flags.csv         # 非正、重复、异常及原始值；不静默修复
  manifest.json             # 来源版本、取数条件、抓取时刻、每文件 SHA-256
  README.md                 # 单位、修订限制、PIT_INFERRED/UNVERIFIED 及重现条件
```

完整导出要包含 **在窗口内存续的所有实际月份**，不能只从当前存活清单筛选，也不能把交割年月限制在 2025 年以内；实测 2025-12-31 的 BU 列表包含 BU2712。上市日期可能早于 2020，应保留法定元数据。未知修订/首次可得时间按合同披露，不要求先建设正式 PIT 存储。日历不能复用 A 股日历冒充两交易所日历；不跨选择节点前填、不把结算限制到 OHLC 范围。

**有条件的最小 CR（备选，未批准/未实现）**：只有 Owner 已提供可访问上游、且无法直接产出上述离线文件时，申请 `CR-P2-OFFLINE-01`，限一个研究目录中的固定五品种/2020—2025 导出与质量校验脚本，预计 1—2 人日、不改 src/依赖/已发布契约/生产 Provider。必须先过三个指定日全月份、关键字段与历史元数据样本；遇到权限失败、关键缺口无现成替代或需要建设补洞平台即停止。是否另建生产能力不包含在此 CR 内。

风险分类：

- **CONFIRMED_DEFECT（候选输入）**：新浪样本在目标窗口的 125 行非正结算，无法原样满足正结算使用；不是确认 chstockdata 已发布代码有缺陷。三条官方无成交月份的空 O/H/L 作为来源缺失保留，不自动判为坏行情。
- **UNRESOLVED_RISK**：DCE 完整月份身份、逐日覆盖、历史乘数/tick/单位/上市退出与修订语义尚未验证；外部供应商当前权限与文件未到位。这些是交付证据缺口，不能当成策略现金期。
- **SPECULATIVE_CONCERN**：未采样日期可能还有其他缺口；本轮不据推测增建平台或扩大调查。
- **FUTURE_ENHANCEMENT**：通用期货 Provider、全市场数据平台、生产 PIT、分钟执行系统均不在当前合同的工程前置内。

本轮不专项审查商业授权，也未获得或宣称正式商业使用权。建议下一步只由 **Owner 选择提供一份现成导出，或授权有权限的成熟供应商导出**；先以同一合同验收数据，失败则给出具体缺口停止。没有供应商输入时不重复免费源宽泛调查；有合格现成包时不增加工程。
