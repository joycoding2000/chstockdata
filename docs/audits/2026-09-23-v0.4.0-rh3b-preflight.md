## 5. PyPI 当前发行与 Trusted Publisher

PyPI 项目侧 Trusted Publisher 配置需要登录项目设置，本环境无法只读读取该私有设置。预期配置必须精确对应：

| 字段 | 预期值 |
| --- | --- |
| GitHub owner/repository | joycoding2000/chstockdata |
| Workflow file | publish.yml |
| Environment | pypi |

因此 PYPI_TRUSTED_PUBLISHER = OWNER_CONFIRMATION_REQUIRED。workflow 中存在 environment 和 id-token 权限只证明本地配置正确，不证明 PyPI 账户端 publisher 已注册或 OIDC exchange 成功。
