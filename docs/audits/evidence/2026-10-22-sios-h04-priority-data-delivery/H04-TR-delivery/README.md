# H04 离线消费者输入

本包只供独立消费者审阅，不授权研究恢复。2024–2025 是来源调查边界，不是新冻结策略窗口。

```text
python tools/build_delivery.py --root . --output .
python tools/receive_delivery.py . --report ../independent-validation.json
```

完整原件复核需要已有可选 pypdf；缺失时接收器明确阻断，不会静默降级为全验证通过。

原始价格单位元/份，量股，额人民币元，保留 float32 精确值与源字节定位。

每日经济回报因子为 (当日原始收盘价+当日除息现金)/前收盘价。链接指数是标准毛总回报恒等式，隐含除息再投资的数学口径；不是支付前可执行再投资。另给一份不再投资、现金留存的每份财富账：价格+应收+已分配现金。权益只在除息生效，保守日末可用后再将应收转现金、不再产生一次收益。可用现金按官方领取日结束后、下一合格交易时段保守处理；真实券商到账未知。

基金持仓只作为具名历史产品暴露代理，绝不是指数真实成分或权重。行业归一映射保留原名和彭博来源；分类历史版本未认证。价值、质量、股票利率敏感性与连续历史母池/指数权重缺失，不能计零。禁止用后发报告回填历史已知。
