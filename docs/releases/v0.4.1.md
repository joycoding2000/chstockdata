# chstockdata v0.4.1

The v0.4.1 release is published to PyPI and available as a GitHub Release. It
preserves the v0.4.0 runtime scope and adds no new runtime API or behavior. The
package version advances to 0.4.1; RH3-B.1's deterministic test-isolation
correction is included in the release source. The original v0.4.0 tag and its
failed release audit remain unchanged.

## Included API surface

The six additive structured entry points introduced for v0.4.0 remain:

- `fetch_realtime_quotes`
- `fetch_daily_bars`
- `fetch_trading_calendar`
- `fetch_suspension_info`
- `fetch_delisting_status`
- `fetch_tradability`

See [MIGRATION.md](../../MIGRATION.md) for usage and result semantics.
